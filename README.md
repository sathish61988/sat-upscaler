Sat Upscaler

AI-style image upscaler built with HTML, CSS, and JavaScript.

Live Demo

https://sat-upscaler.vercel.app

---

Features

- AI-style image enhancement
- 2x and 4x upscale modes
- Before / After comparison slider
- Drag and drop upload
- Mobile responsive design
- Dark premium UI
- Image sharpening
- Multiple export options
- Fast browser-based processing

---

Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Canvas API
- Vercel Deployment

---

How It Works

1. Upload an image
2. Choose upscale mode
3. Process the image
4. Compare results
5. Download enhanced image
